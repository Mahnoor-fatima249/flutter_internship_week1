## 📋 Overview

This is the **Week 1** project of a 1-month Flutter Development Internship. The focus this week was on learning Flutter fundamentals, setting up the development environment, and building the first set of UI screens.

## 🎯 Objectives

- Install and configure Flutter SDK with Android Studio / VS Code
- Understand the Flutter project folder structure
- Build foundational UI screens using core Flutter widgets

## ✨ What's Built

| Screen | Description |
|--------|-------------|
| **Splash Screen** | App intro with gradient background, Flutter logo, auto-navigation after 3 seconds |
| **Login Screen** | Email & password fields with validation, gradient card UI, navigation to Home |
| **Sign Up Screen** | Full name, email & password fields, form validation, back navigation |
| **Home Screen** | Dashboard layout with welcome banner and feature cards grid |

## 🧱 Widgets Used

| Widget | Purpose |
|--------|---------|
| `Scaffold` | Screen structure with body |
| `AppBar` | Top navigation bar |
| `Text` | Display text content |
| `Icon` | Flutter dash, email, lock, person icons |
| `TextField` | User input for email & password |
| `ElevatedButton` | Login & Sign Up buttons |
| `Row` & `Column` | Layout arrangement |
| `Container` | Styled boxes with gradients & shadows |
| `Image` | Flutter logo display |

## 📂 Project Structure

```
lib/
├── main.dart                 # App entry point
└── screens/
    ├── splash_screen.dart    # Splash / Loading screen
    ├── login_screen.dart     # Login authentication screen
    ├── signup_screen.dart    # User registration screen
    └── home_screen.dart      # Home dashboard screen
```

## 🛠️ Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/) with Flutter extension
- Emulator configured or physical device connected

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahnoor-fatima249/flutter_internship_week1.git

# Navigate to project directory
cd flutter_internship_week1

# Install dependencies
flutter pub get

# Run the app
flutter run
```
